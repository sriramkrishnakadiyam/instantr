# InstantAI Recipes

This is a Next.js web application called "InstantAI Recipes", a modern, responsive, full-stack solution for recipe generation and exploration.

## Features

- **AI-Powered Recipe Generation**: Generate unique recipes based on ingredients, cuisine, dietary preferences, and difficulty level.
- **User Authentication**: Secure sign-up and sign-in functionality.
- **Recipe History**: Save and revisit your generated recipes.
- **Cuisine Exploration**: Browse a vast collection of recipes from various cuisines.
- **Personalized Recommendations**: Get AI-driven recipe suggestions tailored to your taste.
- **Dark Mode**: Switch between light and dark themes for comfortable viewing.

## Getting Started

To get started with the development server, run:

```bash
npm run dev
```

This will start the Next.js application on `https://instantr.vercel.app`.
