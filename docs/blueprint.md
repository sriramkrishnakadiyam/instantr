# **App Name**: GourmetAI Recipes

## Core Features:

- Recipe Generation: Generate recipes based on ingredients, cuisine, dietary preferences, and difficulty using AI.
- User Authentication: Secure sign-up and sign-in functionality with JWT authentication to manage user accounts and recipe history.
- Recipe History: Save generated recipes to user history stored in MongoDB, allowing users to review past creations.
- Cuisine Browsing: Display a comprehensive list of cuisines. Display recipes for a selected cuisine, fetched from the MongoDB database
- AI Recipe Recommendations: AI tool providing personalized recipe recommendations based on user preferences (cuisine, ingredients, dietary restrictions) by querying the database
- Contact Support: Provide a contact form that sends emails to the support team.
- Settings and Preferences: Allow users to set preferences for dark mode, units of measurement, dietary requirements and favorite recipes.

## Style Guidelines:

- Primary color: Saffron (#FF8C00), a warm, inviting color that reflects the culinary theme.
- Background color: Light desaturated saffron (#FAF0E6) to create a gentle, warm backdrop (HSL: 30, 70%, 95%).
- Accent color: Deep Red (#8B0000), for highlights, buttons, and interactive elements, providing a sophisticated contrast.
- Headline font: 'Playfair', a modern serif, imparting elegance and sophistication.
- Body font: 'PT Sans', a humanist sans-serif to ensure legibility and contemporary style. Using 'Playfair' for headlines and 'PT Sans' for the body strikes the correct balance.
- Use consistent, elegant icons related to food, ingredients, and cooking actions.
- Implement glassmorphism cards with soft shadows to create a modern, visually appealing interface. Cards shall contain blurred images of biryani, chicken leg pieces, eggs, tomatoes, carrots in the background
- Incorporate smooth transitions and hover effects for a premium user experience.
